# Lewis Masha — Personal Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — layout, responsive styling and visual components
- `script.js` — mobile navigation and current-year footer

## Publish with GitHub Pages
1. Open [the portfolio repository](https://github.com/luee-dev/luee-dev.github.io).
2. Select **Add file → Upload files**.
3. Upload the contents of this folder to the repository root (not the enclosing folder).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then save.
8. Once GitHub Pages finishes deploying, visit https://luee-dev.github.io/.

## Before publishing
- Add a verified LinkedIn profile URL if you want it displayed.
- Add a public email address only if you want recruiters to contact you directly.
- Add a CV link after uploading the final CV to a stable public location.
- Add project screenshots and verified certificate links when available.

The portfolio intentionally avoids invented performance metrics, unverified contact details and claims that work-in-progress projects are production deployments.
