## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the deployment to complete.

The site uses HTML, CSS and vanilla JavaScript. Project descriptions distinguish work in progress from completed portfolio projects. Add verified contact details, screenshots and public credential links as they become available.
